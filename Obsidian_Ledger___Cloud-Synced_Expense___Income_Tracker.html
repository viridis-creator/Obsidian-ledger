Cloud Sync & Self-Hosting Guide

Obsidian Ledger uses Firebase Authentication and Cloud Firestore with offline persistence so your expenses and monthly income sync automatically across your phone and computer.

If hosting your own copy on Netlify or GitHub Pages:

  1. Create a free project at console.firebase.google.com.
  2. Enable Authentication (Email/Password and Google providers) and add your hosting domain under Authorized Domains.
  3. Enable Cloud Firestore and set security rules so each user can only read/write their own users/{uid} data.
  4. Paste your web app's firebaseConfig object into the FALLBACK_FIREBASE_CONFIG constant inside this file's script.

Without a custom Firebase config on an external host, you can still use Local Offline Mode with full CSV/JSON backup & restore.
